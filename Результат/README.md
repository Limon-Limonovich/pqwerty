# Готовая работа

- **Отчёт_по_уроку.docx** — отчёт Word: краткие ответы, основные результаты и выводы.
- **Практические_задания.xlsx** — одна книга Excel: 18 листов, 13 диаграмм. Все 7 задач, 4 самостоятельные задачи, отчёт «ТекстильПром» и все 5 итоговых вариантов.

Начните с листа `00_Навигация`. Оформление стандартное: без заливок и декоративных стилей, с обычной сеткой. Открывайте книгу в Excel с автоматическим вычислением. Word фиксирует исходные результаты и не обновляется при изменении Excel.

Где исходные данные не указаны в сценарии, использованы отмеченные учебные примеры. Исправления формул сценария объяснены в Word. Персональные данные учащегося не выдумывались.

## Воспроизводимость

Из корня репозитория:

```sh
python -m venv .venv
.venv/bin/pip install -r scripts/requirements.txt
.venv/bin/python scripts/create_deliverables.py
.venv/bin/python scripts/verify_deliverables.py
```

Проверка охватывает структуру файлов, наличие формул и сохранённых результатов, расчёты, даты, граничные примеры, количество и типы диаграмм. Проверка не заменяет пересчёт и визуальное открытие в настольных Excel/Word.
